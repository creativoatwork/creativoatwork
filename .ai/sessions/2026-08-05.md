## Findings worth carrying forward

- Firebase is a **static host only** here — no Auth, Firestore, Storage, or Functions, and no Firebase SDK in the bundle. Easy to wrongly assume otherwise given the Firebase config files.
- The contact endpoint is the only attack surface and has no rate limiting; the honeypot is the sole abuse control.
- `VITE_CONTACT_URL` is inlined at build time, so a Worker URL change requires a frontend rebuild — not just a config change.
- `npm run build` (via `tsc -b`) is the only automated gate in the repository.
- `cleanUrls` in `firebase.json` is load-bearing for the `/terms` link.
